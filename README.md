# MBL - Mon Beau Lieu

Application web moderne développée avec **Next.js 15** et **React 19**.

## 🚀 Démo en ligne

Visitez [https://mbl-app.vercel.app](https://mbl-app.vercel.app) pour voir lapplication en action.

## ✨ Fonctionnalités

- **Design moderne** - Interface élégante et responsive
- **Pages multiples** - Accueil, À propos, Services, Contact
- **Formulaire de contact** - Avec validation et feedback visuel
- **SEO optimisé** - Sitemap, robots.txt, métadonnées
- **Performances** - Build statique optimisé par Next.js

## 🛠️ Stack Technique

- **Next.js 15** - Framework React
- **React 19** - Bibliothèque UI
- **TypeScript** - Typage fort
- **CSS personnalisé** - Design system intégré

## 📦 Installation

```bash
npm install
npm run dev    # Développement local
npm run build  # Build de production
npm start      # Serveur de production
```
